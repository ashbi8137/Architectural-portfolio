# Architectural Portfolio

A modern and minimal architectural portfolio showcasing selected projects, design philosophy, and professional work.  
Designed to present architectural ideas with clarity, elegance, and strong visual focus.

## Overview

This repository contains a personal architectural portfolio featuring residential, commercial, and conceptual projects.  
The portfolio emphasizes clean layouts, high-quality visuals, and structured project presentation.

## Features

- Minimal and contemporary design  
- Fully responsive layout  
- High-resolution project images and renders  
- Clear project descriptions and specifications  
- Smooth and intuitive navigation  

## Tech Stack

- **Framework:** Next.js  
- **Language:** TypeScript  
- **Styling:** Tailwind CSS  

## Getting Started

To run the project locally:

npm install
